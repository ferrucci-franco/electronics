# Strings for `texts()` (FR is the apps' default language)

```js
const PI_TEXTS = {
  fr:{fitX:'Ajuster X', fitY:'Ajuster Y', fitAll:'Tout ajuster',
      legendShow:'Afficher la légende', legendHide:'Réduire la légende',
      zoomHint:'Glissez sur le côté pour zoomer en X, vers le haut ou le bas pour zoomer en Y, en diagonale pour une fenêtre'},
  en:{fitX:'Fit X', fitY:'Fit Y', fitAll:'Fit all',
      legendShow:'Show legend', legendHide:'Minimize legend',
      zoomHint:'Drag sideways to zoom on X, up or down to zoom on Y, diagonally for a window'},
  es:{fitX:'Ajustar X', fitY:'Ajustar Y', fitAll:'Ajustar todo',
      legendShow:'Mostrar leyenda', legendHide:'Minimizar leyenda',
      zoomHint:'Arrastra de lado para ampliar en X, arriba o abajo para ampliar en Y, en diagonal para una ventana'}
};
// install(..., {texts: () => PI_TEXTS[LANG]})
```

Do not add an on-screen help text describing the gestures: the owner removed one ("es bastante intuitivo").
The zoom hint is the exception: it appears only while a slow double tap waits for its drag.
